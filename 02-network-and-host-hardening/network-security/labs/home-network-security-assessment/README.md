# Home Network Security Assessment

> **Evidence status:** Partial. The wireless module contains two sanitized screenshots and initial scan observations; its walk test and remaining evidence are pending. Router notes are historical and unverified. This combined assessment is not complete.

## Goal

Review wireless conditions and customer-accessible router security settings on a network you own or are authorized to assess. Identify practical improvements while keeping network and household identifiers private.

## Assessment modules

1. **Wireless survey:** [Wi-Fi assessment runbook](../wireless-assessment/wifi-assessment-with-inssider.md) covers signal and channel observations, security settings, screenshots, and redaction. Initial scan observations and two sanitized screenshots are recorded; walk-test measurements and remaining evidence are still outstanding.
2. **Router configuration review:** [Home router security review](../home-network-hardening.md) covers administrative access, Wi-Fi encryption, WPS, guest/client isolation, remote administration, firmware, and rollback. Its historical observations have not been reverified and must not be reported as current findings.

## Combined workflow

1. Confirm authorization and document the device and assessment scope without recording identifying values.
2. Collect wireless signal, channel, and security observations, then review the router controls available to the operator.
3. Separate observed settings from unavailable or unverified controls; prioritize recommendations by their security benefit and compatibility impact.
4. Apply only changes you understand and are authorized to make. Record a rollback path and verify connectivity and settings afterward.
5. Sanitize screenshots and exports before publication; do not include SSIDs, BSSIDs, addresses, credentials, account names, device identifiers, or location details.

## Evidence and limits

The wireless observations and the router's historical notes come from different work and have different evidence status. Do not combine them into a single finding or imply that a router setting was verified by the wireless scan. Complete both modules and document their actual results before presenting this as a finished assessment.

Use the module runbooks for detailed procedures, safety guidance, results, and references.

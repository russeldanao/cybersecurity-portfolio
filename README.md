# Cybersecurity Portfolio

A curated set of networking and security study notes, cited case studies, and lab study guides prepared for future reruns.

> **Lab status:** Lab write-ups are draft study guides for future reruns. Historical procedures and results are unverified, and prior co-op evidence is not available for verification. Do not treat existing notes or screenshots as proof of completed work. Use the [lab study template](LAB-STUDY-TEMPLATE.md), sanitize before publication, and add only freshly reviewed evidence.

## Portfolio areas

- [01 — Identity & Cloud IAM](01-identity-and-cloud-iam/README.md): cloud fundamentals and Windows Server directory-services study materials; Entra ID lifecycle labs are planned.
- [02 — Network & Host Hardening](02-network-and-host-hardening/README.md): network references and draft Windows protocol-hardening study guides.
- [03 — Detection & Incident Response](03-detection-and-incident-response/README.md): case studies, detection notes, and blue-team lab drafts.
- [04 — GRC & Risk Management](04-grc-and-risk-management/README.md): framework and policy materials; the NIST CSF 2.0 assessment package is planned.
- [05 — AI & Automation Security](05-ai-and-automation-security/README.md): Python-for-cybersecurity notes and a planned agentic-workflow security study.
- [06 — Study Guides & Notes](06-study-guides-and-notes/README.md): sanitized coursework summaries and foundational references.

## Platform and data security

Use the [Platform and Data Security index](07-platform-and-data-security/README.md) for foundational Linux and local database practice, grouped by the environment they share.

The folder structure contains only the selected materials included in this publication copy. Source notes are written in original wording and cite public references. No raw packet captures, school handouts, or copied slides are included.

## Use and safety

Run configuration-changing commands only in a disposable virtual machine that you own, after taking a snapshot. Network tests are limited to owned or explicitly authorized systems. Lab reports state their evidence scope and limitations; drafts are marked as such until real output replaces the placeholders.
